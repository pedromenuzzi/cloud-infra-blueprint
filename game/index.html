How the dojo works

  1. Pick the glowing mission. Read the lesson, do the task in your terminal or VS Code.
  2. Run ./check B.M from the repo root to grade one mission, or ./check to grade everything.
  3. Passing a mission banks its XP, advances Tux's belt, and updates this board automatically.

New here or on Windows? See SETUP.md to get a Linux shell in ~10 min (WSL2), then come back and run ./play. This board reads game/progress.json; keep ./play running and it refreshes on its own.
